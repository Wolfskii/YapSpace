# Architecture Decision Records

Each record follows the template in this folder. The summaries and the full decisions are in
[architecture/overview.md](../architecture/overview.md). Provisional records need validation in the task named in
their Revisit line.

| # | Title | Status | Decision |
|---|---|---|---|
| [0001](./0001-backend-framework.md) | Backend framework | Accepted | axum 0.8 on tokio, with tower-http middleware. |
| [0002](./0002-database-and-data-access.md) | Database and data access | Accepted | PostgreSQL 18 with sqlx 0.9. Compile-time checked query macros, an offline query cache in .sqlx/, and embedded migrations. |
| [0003](./0003-modular-monolith.md) | Modular monolith | Accepted | One binary with internal modules (api, domain, db, realtime). One deployable. |
| [0004](./0004-rest-api-with-openapi.md) | Rest api with openapi | Accepted | REST under /v1 with problem+json errors, keyset pagination, and an OpenAPI 3.1 document generated by utoipa. The extension types come from that document. |
| [0005](./0005-realtime-websocket.md) | Realtime websocket | Accepted | A WebSocket for subscriptions only. Writes go over REST. Resume uses seq cursors (after_seq). |
| [0006](./0006-event-distribution.md) | Event distribution | Accepted | In-process broadcast per discussion now. An EventBus trait later, with Postgres LISTEN/NOTIFY, then NATS if NOTIFY saturates. |
| [0007](./0007-url-identity.md) | Url identity | Provisional | Versioned, deterministic identity keys built on the server. Site adapters for permalinks. No implicit merging. Admin-only merges. Shared test vectors (90 at the time of writing). |
| [0008](./0008-authentication.md) | Authentication | Accepted | Username and password (argon2id), opaque session tokens (only SHA-256 stored), and a one-time recovery code. No email in the MVP. |
| [0009](./0009-caching.md) | Caching | Accepted | No cache in the MVP. An in-process moka cache later for hot reads. Redis only when several instances must share state. |
| [0010](./0010-docker-and-reverse-proxy.md) | Docker and reverse proxy | Accepted | Docker Compose on one VPS. Caddy in front for TLS. A distroless non-root image. A one-shot migrate service. |
| [0011](./0011-extension-architecture.md) | Extension architecture | Provisional | WXT 0.21 with Svelte 5 and TypeScript, one codebase for Chrome and Firefox. The panel runs in an extension iframe inside a closed shadow root and is injected only on user action. |
| [0012](./0012-repository-structure.md) | Repository structure | Accepted | A monorepo: crates/ (Rust), extension/ (WXT), spec/ (shared test vectors), deploy/ (ops), docs/ (plans, architecture and ADRs). |
| [0013](./0013-observability.md) | Observability | Accepted | JSON logs via tracing, Prometheus metrics on an internal port, and an optional Grafana profile. OpenTelemetry tracing is deferred. |
| [0014](./0014-search.md) | Search | Accepted | No search in the MVP. Postgres full-text search first. A dedicated engine only after measured need. |
| [0015](./0015-desktop-framework.md) | Desktop framework | Provisional | Tauri 2 for a desktop client in Phase 7. It reuses yapspace-identity and the REST and WebSocket API. |
